# sales-monitoring-dashboard

1.Project Title:
E-Commerce Sales Analytics Dashboard using (Power BI).

2.Short Description:
This project showcases an interactive Power BI dashboard developed to analyze e-commerce sales data and generate actionable business insights. The dashboard helps visualize key performance metrics such as sales revenue, profit trends, customer purchasing patterns, and product performance. It is designed to support data-driven decision-making through clear, dynamic, and visually engaging reports.

3.Tech Stack:
Power BI, DAX (Data Analysis Expressions), Data Visualization, Data Cleaning & Transformation, Excel/CSV Data Handling.

4 Data Source:
E-commerce sales dataset in Excel/CSV format used for data cleaning, modeling, and visualization practice.

5.Features / Highlights:
Interactive dashboard with slicers and filters
Sales, profit, and performance KPI tracking
Region-wise and category-wise sales insights
Customer behavior and product performance analysis
Clean, professional data visualization for business reporting.
